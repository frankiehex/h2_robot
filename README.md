# 协作机器人三明治柔性生产线 · 概念设计

> 以法奥（Fairino）、节卡（JAKA）、优傲（UR）协作机器人为核心，
> 三轨道步进式输送线（3×3 九宫格工作窗口），覆盖 **原料预处理 → 组装 → 切割 →
> 包装 → 装盒 → 装箱 → 码垛 → 溯源** 的全流程柔性生产线。

详细设计见 [`docs/concept-design.md`](docs/concept-design.md)。

**工位单元控制**（视觉引导取放 + 多机调度与区域互锁）：
设计见 [`docs/cell-control-design.md`](docs/cell-control-design.md)，
代码骨架见 [`cellctl/`](cellctl/)（含仿真驱动，无硬件可跑通：
`python3 -m cellctl.main --cycles 3`；互锁测试：`python3 tests/test_zone_lock.py`）。

`http://127.0.0.1:8700`（`cellctl/dashboard/panel.html` 单独打开为网页内仿真 DEMO）。

## 核心思路一页速览

1. **用并行补速度**：协作机器人单臂节拍慢（一次取放约 3–5 s），
   用 3 条轨道并行 + 步进节拍设计，每个步进周期同时产出 3 份三明治，
   把"单臂慢"摊薄成"整线快"（设计目标 ≥ 600 份/小时）。
2. **3×3 九宫格工作窗口**：每个工位面前始终有 3 行 × 3 列共 9 个载具格。
   机器人做完面前一行 3 格，输送线前进一个行距。3 行深度给了每个工位
   最多 3 个节拍的调度余量——慢工序不卡整线。
3. **载具化生产**：三明治不直接接触皮带，全程放在带 RFID/二维码的
   食品级定位模盒（载具）里。载具既是定位基准（免视觉也能精确取放），
   也是溯源的数据载体。
4. **模块化工位小车**：每个工位（切火腿、放蛋皮、打酱……）做成标准接口的
   可推走/可对接的独立模块，换产品配方 = 换工位组合 + 下发新配方，
   这是"柔性"的机械基础。
5. **配方驱动 + 逐层溯源**：MES 按配方调度工位；条码/RFID 在
   三明治 → 袋 → 盒 → 箱 → 垛 五级逐层聚合（GS1 标准），
   任意一包可回溯到火腿批次、吐司批次、当班参数。

## 机器人选型速览

| 品牌 | 用在哪 | 理由 |
|------|--------|------|
| 优傲 UR（e 系列 / UR20） | 超声波切割、码垛等关键/高负载工位 | 精度与生态最成熟，20 kg 负载可码垛 |
| 节卡 JAKA（Zu / Pro 系列） | 视觉引导取放（蛋皮、火腿上料） | 一体式关节 IP54、无线示教，产线部署快 |
| 法奥 Fairino（FR 系列） | 数量最多的常规取放工位（吐司、装袋、装盒） | 性价比高，适合"多臂摊薄节拍"的策略 |
